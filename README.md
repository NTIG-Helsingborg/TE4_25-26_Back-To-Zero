# Back To Zero
Rouge-Like Adventure

## ⚠️ Important: Firewall Warning

**This project does not have code signing**, which means Windows Firewall may block the application.

To run this project, you must either:

1. **Run as Administrator** - Right-click the executable and select "Run as administrator"
2. **Allow through Firewall** - Right-click the launch file → Properties → Allow app through firewall

---

## Getting Started

Run `Back To Zero.exe` to launch the game.
